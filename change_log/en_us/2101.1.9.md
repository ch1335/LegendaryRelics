# Changelog

## 2101.1.9

Balance

- New attribute **Seeking**: rare mobs whose spawn weight is below 2% of the whole spawn list get their weight raised to base weight x (1 + Seeking), using the highest Seeking among players within 128 blocks, uncapped. Only affects natural spawning; mob spawners and mobs placed by structures are unaffected
- **Frost Shard** drop chance is now: base 5%, +0.5% per Looting level, +0.5% per point of the attacker's Luck, then scaled by difficulty (Normal x1.15, Hard x1.3)


Datapack Support

- New **loot injectors**: datapacks can place json files under `data/<namespace>/loot_injecter/` to add or remove loot pools and entries, or attach conditions and item functions to existing entries. Targets can be chosen by loot table id, namespace, path prefix, and entity or block tags
